- **Major (X.0)**: Mudanças significativas
- **Minor (X.Y)**: Novas funcionalidades ou melhorias
- **Patch (X.Y.Z)**: Correções menores

### **Nomenclatura**
- Formato: `RELATORIO_[CATEGORIA]_[DATA].md`
- Data: Formato `YYYY_MM_DD` ou `YYYY_MM`
