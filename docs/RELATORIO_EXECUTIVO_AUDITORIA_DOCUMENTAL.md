## 🔄 Processos Estabelecidos

### **1. Processo de Atualização**

1. Criar/atualizar documento seguindo template padrão
2. Adicionar metadados obrigatórios
3. Validar com `scripts/validate_docs.py`
4. Atualizar `changelog_documentacao.md`
5. Commit com mensagem padronizada

### **2. Processo de Arquivamento**

1. Validar necessidade de arquivamento
2. Gerar hash SHA256
3. Criar metadados JSON
4. Mover para `legacy_archive/`
5. Atualizar changelog e índices

### **3. Processo de Validação**

1. Executar `scripts/validate_docs.py` antes de commit
2. Verificar avisos e erros
3. Corrigir problemas identificados
4. Re-executar validação até passar
