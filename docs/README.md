## 🚀 **Quick Start**

### **Executar o Projeto**
```bash
# Instalar dependências
pip install -r requirements.txt

# Executar testes
python -m pytest tests/

# Iniciar servidor
python main.py --port 8001
```

### **Acessar API**
- **Swagger UI**: http://localhost:8001/docs
- **ReDoc**: http://localhost:8001/redoc
- **Base URL**: http://localhost:8001/api/v1
