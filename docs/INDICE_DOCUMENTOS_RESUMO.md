## 🔄 Política de Consolidação

### **Documentos Mantidos Separadamente**

Documentos de resumo são mantidos separadamente porque:
- **Contextos Diferentes**: Cada resumo aborda contexto específico
- **Rastreabilidade**: Facilitam rastreabilidade histórica
- **Referências**: Utilizados como referência em diferentes documentos

### **Consolidação Futura**

Documentos podem ser consolidados quando:
- Informações se tornam duplicadas
- Contexto se torna idêntico
- Rastreabilidade não é mais necessária
